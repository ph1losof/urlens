# Support

## Getting Help

Read the README and search existing issues before asking for help. For reproducible incorrect
behavior, use the bug report form. For API or project proposals, use the feature request form.
General usage questions may be opened in GitHub Discussions when Discussions are available.

Please include the `urlens` version, runtime and version, a minimal example, expected behavior,
and actual behavior. Maintainers review requests as time permits; no individual response time or
support-level agreement is guaranteed.

## Security

Do not report suspected vulnerabilities through public support channels. Follow the private
reporting process in [SECURITY.md](SECURITY.md).
